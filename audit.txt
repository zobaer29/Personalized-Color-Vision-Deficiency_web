Detailed Restormer_RDB / Modified_Conditional_Restormer Layer Specifications
--------------------------------------------------------------------------------
1. Input Layer (append_condition_channels):
   - Input: 3-channel RGB image tensor (B, 3, H, W) normalized to [0.0, 1.0].
   - Conditioning: One-hot vector of condition_id [0, 1, 2] spatially expanded
     to (B, 3, H, W).
   - Concatenated Tensor: (B, 6, H, W) passed to patch_embedding.

2. Patch Embedding:
   - Conv2d(6, 16, kernel_size=3, padding=1, bias=False)

3. Hierarchical Encoder:
   - Level 1: RestormerBlock(channels=16, heads=1) x 1 block
   - Downsample 1: Conv2d(16, 8, k=3, p=1) -> PixelUnshuffle(downscale=2) -> 32 ch
   - Level 2: RestormerBlock(channels=32, heads=2) x 1 block
   - Downsample 2: Conv2d(32, 16, k=3, p=1) -> PixelUnshuffle(downscale=2) -> 64 ch

4. Latent Bottleneck:
   - RestormerBlock(channels=64, heads=4) x 2 blocks
   - ResidualDenseBlock(RDB): 3 dense Conv2d(64, 64) with GELU activations +
     1x1 Conv fusion -> residual skip addition.
   - CBAM (in Modified_Conditional_Restormer): Channel attention (AvgPool + MaxPool
     MLP) followed by 7x7 spatial attention.

5. Hierarchical Decoder:
   - Upsample 2: Conv2d(64, 128, k=3, p=1) -> PixelShuffle(upscale=2) -> 32 ch
   - Skip Connection 2: Concat with Level 2 encoder features -> 1x1 Conv(64 -> 32)
   - Decoder Level 2: RestormerBlock(channels=32, heads=2) x 1 block
   - Upsample 1: Conv2d(32, 64, k=3, p=1) -> PixelShuffle(upscale=2) -> 16 ch
   - Skip Connection 1: Concat with Level 1 encoder features -> 1x1 Conv(32 -> 16)
   - Decoder Level 1: RestormerBlock(channels=16, heads=1) x 1 block

6. Output Projection & Bounded Residual Formulation:
   - Output Projection: Conv2d(16, 3, kernel_size=3, padding=1, bias=False)
   - Residual: 0.5 * tanh(Output_Projection)
   - Output: clamp(Original_Image + Residual, 0.0, 1.0)
   - Benefit: Bound residual prevents artifact explosion and ensures clean color
     shifts without altering natural lighting.

7. Attention Mechanism: Multi-Dconv Head Transposed Attention (MDTA):
   - Computes cross-covariance attention across channel dimensions (C x C) instead
     of spatial dimensions ((HW) x (HW)).
   - Computational complexity is linear with respect to image resolution, enabling
     arbitrary image resolutions without out-of-memory errors on client requests.

Data Preprocessing & Augmentation Pipeline:
--------------------------------------------------------------------------------
- Input Normalization: Pixel intensities mapped to [0.0, 1.0] float32 tensors.
- Training Augmentations (PairedTransform):
  1. Bicubic resize to 1.12x of target size (143x143 for 128x128 crop).
  2. Random spatial paired crop (128x128).
  3. Paired random horizontal flip (p = 0.50).
  4. Paired random bilinear rotation in range [-5.0, 5.0] degrees.
- Validation / Testing: Direct bicubic resize to target resolution (128x128).

--------------------------------------------------------------------------------
Multi-Component Colour-Aware Loss (CommonColourAwareLoss):
--------------------------------------------------------------------------------
Equation:
  Loss_total = (1.0 * L1) + (0.30 * L_MS-SSIM) + (0.15 * L_LAB) + (lambda_sim * L_sim)

Components:
  - L1 Loss: Pixel-wise absolute difference between prediction and corrected target.
  - MS-SSIM Loss: 1.0 - ms_ssim(pred, target, data_range=1.0, win_size=7).
  - CIELAB Loss: Smooth L1 loss in perceptual CIELAB space via normalized_lab:
      L* / 100.0, ab / 128.0.
  - CVD Simulation Loss (Optional, default 0.0): Consistency penalty against
    sRGB linear simulation matrices (CVD_MATRICES).

API Endpoints:
--------------------------------------------------------------------------------
1. POST /api/v1/recolor
   - Purpose: Real-time image recolorization with personalization blending.
   - Request Body:
     {
       "image_base64": "data:image/jpeg;base64,...",
       "condition": "Deuteranopia",
       "condition_id": 1,
       "severity": 0.85,
       "return_format": "webp"
     }
   - Response Body:
     {
       "status": "success",
       "recolored_base64": "data:image/webp;base64,...",
       "inference_time_ms": 12.4,
       "condition_id": 1,
       "cached": false
     }
   - Personalization Formula (personalization.py):
       Output = (severity * Model_Prediction) + ((1.0 - severity) * Original_Image)
   - Caching Engine: In-memory thread-safe LRU Cache (cache.py).
       Cache Key: SHA256(image_bytes) + condition_id + round(severity * 100).
       Cached retrieval latency: < 1.0 ms.

2. POST /api/v1/diagnose
   - Purpose: Evaluates interactive Ishihara / D-15 questionnaire from extension.
   - Scoring Logic: Computes error distributions across Protan, Deutan, and Tritan
     confusion plates; returns diagnosed condition and severity percentage (0-100%).

3. GET /health
   - Purpose: Verifies API health, compute device (CPU/CUDA), weights status, and
     active cache size.

4. GET /docs
   - Interactive OpenAPI / Swagger UI.
